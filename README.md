# 纯眼动打字系统

这是一套完全独立的 Windows 纯眼动打字系统，不需要脑电设备。系统由两个程序组成，所有注视数据仅通过本机 `127.0.0.1:9101` 传递，文本和实验记录不会上传网络。

## 使用顺序

1. 打开 `眼动采集校准\眼动采集校准.exe`。
2. 选择摄像头并点击“连接摄像头”。
3. 根据需要勾选“校准后进行精度验证（推荐）”，然后点击“重新校准…”。
4. 在全屏子菜单选择“快速校准（推荐）”或“精确校准”。
5. 校准保存后会自动输出眼动数据；“暂停输出”只暂停 UDP 数据，摄像头预览仍会继续。
6. 打开 `纯眼动打字器\纯眼动打字器.exe`。
7. 在开始页选择是否显示实时眼动位置，并设置凝视停留时间。默认值为 `1.0 秒`，可调范围为 `0.5-3.0 秒`。
8. 眼动状态显示“眼动已连接”后点击“开始实验”。

## 输入与返回

- 主菜单与脑电版一致，包含五组字母及“删除、空格、发送”三个直接命令，共八个目标。
- 字母子菜单为两行三列，包含五个字母和空格；`U-Z` 组显示六个字母。
- 注视目标时会出现红色边框和底部停留进度。关闭实时眼动位置后，选择反馈仍然可见。
- “发送”会把当前输入提交为新的一行并继续实验，不会关闭打字窗口。顶部最多显示三行，可用鼠标滚轮查看更早内容。
- 在约 `2.5 秒`内连续眨眼三次也可以回到主菜单；单次眨眼、长时间闭眼和摄像头丢失不会触发该动作。

## 校准说明

- 快速校准约 `25-35 秒`：九点全屏映射后，对打字区域进行一轮采集和偏差修正。
- 精确校准约 `50-60 秒`：在快速校准基础上，对打字区域进行正序、反序两轮采集并保留更多稳定样本。
- 两种模式都使用至少八帧的稳态样本筛选、屏幕仿射修正、校准范围保护和 Kalman + EMA 平滑。
- 精度验证默认关闭；开启后至少正确命中 `5/6` 才会保存。未通过时只能重校异常区域，旧校准不会被提前覆盖。
- 校准界面和打字界面共享相同目标坐标。按 `Esc` 可取消本次校准并返回采集窗口。
- 更换显示器分辨率、系统缩放比例或摄像头编号后，需要重新校准。

## 数据位置

发布版的设置、校准与会话数据统一保存在：

```text
D:\CodeX\脑电软件设计\cap32_gaze_typing\release\纯眼动打字系统数据
```

该目录包含 `calibration`、`logs`、`sessions` 和 `settings.json`。首次运行新版时，如果此目录为空，程序会从 `%APPDATA%\PureGazeTyping` 无覆盖迁移旧数据。每次实验拥有独立目录，其中包括注视采样、选择事件、会话设置和最终文本。

本次键盘布局使用 `gaze-keyboard-v4-brain-layout` 校准版本。旧版校准文件会保留在磁盘上，但首次使用新版时需要重新校准。

## 连接异常

打字器超过约 `2 秒`收不到采集数据时会暂停选择并显示连接中断。摄像头和采集程序恢复后，连续收到有效注视数据会自动恢复。若提示端口 `9101` 无法使用，请先关闭另一个正在运行的打字器实例。
