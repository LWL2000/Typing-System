# 纯眼动打字系统

这是一套完全独立的 Windows 纯眼动打字系统，不需要脑电设备。系统由两个程序组成，所有注视数据仅通过本机 `127.0.0.1:9101` 传递，文本和实验记录不会上传网络。

## 使用顺序

1. 打开 `眼动采集校准\眼动采集校准.exe`。
2. 选择摄像头并点击“连接摄像头”。
3. 根据需要勾选“校准后进行精度验证”，然后点击“快速校准”。该验证默认关闭。
4. 校准保存后点击“开始输出”，保持采集程序运行。
5. 打开 `纯眼动打字器\纯眼动打字器.exe`。
6. 在开始页选择是否显示实时眼动位置，并设置凝视停留时间。默认值为 `1.0 秒`，可调范围为 `0.5-3.0 秒`。
7. 眼动状态显示“眼动已连接”后点击“开始实验”。

## 输入与返回

- 主菜单包含五组字母和“功能”，所有页面使用相同的两行三列目标位置。
- 注视目标时，底部进度条会显示停留进度。关闭实时眼动位置后，进度和选择反馈仍然可见。
- 字母子菜单顶部有固定“返回”区域，凝视即可回到主菜单。
- 在约 `2.5 秒`内连续眨眼三次也可以回到主菜单；单次眨眼、长时间闭眼和摄像头丢失不会触发该动作。
- 功能菜单提供删除、空格、发送、清空、暂停和返回。清空需要连续确认两次。

## 校准说明

- 快速校准采用自然坐姿的一轮采集，正常约 `8-10 秒`。
- 校准界面和打字界面共享相同目标坐标。
- 精度验证开启后会检查六个按键区域；验证未通过时可以只重校异常区域或仍然保存。
- 更换显示器分辨率、系统缩放比例或摄像头编号后，需要重新校准。

## 数据位置

设置、校准与会话数据保存在：

```text
%APPDATA%\PureGazeTyping
```

每次实验拥有独立目录，其中包括注视采样、选择事件、会话设置和最终文本。运行日志位于 `logs` 子目录。

## 连接异常

打字器超过约 `2 秒`收不到采集数据时会暂停选择并显示连接中断。摄像头和采集程序恢复后，连续收到有效注视数据会自动恢复。若提示端口 `9101` 无法使用，请先关闭另一个正在运行的打字器实例。
